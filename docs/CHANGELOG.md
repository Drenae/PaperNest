# Changelog — PaperNest

Les évolutions importantes de PaperNest sont consignées dans ce fichier.

## En cours

- Mise en place de la documentation de développement.
- Formalisation du caractère strictement privé de l’application.
- Migration progressive des champs vers PaperNestExtension.
- Préparation de l’intégration future de `PaperNestColorPicker`.

## Évolutions récentes

- Migration des filtres vers le composant `PaperNestDropdown`.
- Ajout d’une variante `SearchDropDown` pour les filtres disposant d’un bouton d’effacement.
- Correction de l’affichage du libellé des options de dropdown dans PaperNestExtension.
