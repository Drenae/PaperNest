# Développement de PaperNest

PaperNest est une application privée conçue pour faciliter l’utilisation quotidienne de la compagne d’Adrien sur son ordinateur portable.

## Priorités

- simplicité d’utilisation ;
- fiabilité ;
- confort quotidien ;
- maintenance raisonnable ;
- absence de complexité inutile.

La compatibilité universelle, la distribution publique et les fonctionnalités destinées à un large public ne sont pas des objectifs.

## Organisation de la documentation

- `RULES.md` : règles obligatoires de développement.
- `CHANGELOG.md` : historique des évolutions importantes.
- `roadmaps/ROADMAP_UI.md` : suivi de l’interface et de la migration vers PaperNestExtension.
- D’autres roadmaps seront créées uniquement lorsqu’un chantier réel le justifiera.
