# Roadmap — Identité visuelle PaperNest

## État

L’identité visuelle PaperNest est officiellement terminée et validée.

Le symbole final a été choisi par l’utilisateur, nettoyé, intégré dans `PaperNestGlideRail`, testé dans les états replié et déployé puis validé dans l’application réelle sous Windows.

La source de travail reste conservée dans `src/assets/branding/concepts/logo.svg`. La source officielle et portable est `src/assets/branding/papernest_symbol.svg`.

## Objectif validé

Créer une identité PaperNest cohérente avec l’interface actuelle, lisible sous Windows et directement exploitable dans `PaperNestGlideRail`.
