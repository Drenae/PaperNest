# Roadmap v2.0.0 — Glassmorphism

## Objectif

Faire évoluer progressivement l’interface PaperNest vers un glassmorphism sobre, lisible et cohérent avec le thème jaune et gris foncé, sans modifier l’agencement des écrans.

## Fondations — Cartes

- [x] Rendre `AppCard` translucide avec un flou léger.
- [x] Conserver les couleurs explicites des cartes sémantiques.
- [x] Adapter l’état sélectionné sans perdre l’accent jaune.
- [x] Appliquer un verre sombre aux `PageHeader`.
- [x] Appliquer le verre aux `AppSection` et rendre leur corps transparent.
- [x] Conserver les dimensions, espacements et rayons existants.

## Composants suivants

- [ ] Harmoniser les champs et sélecteurs.
- [ ] Harmoniser les boutons sans réduire leur contraste.
- [ ] Harmoniser les dialogs et leurs variantes sémantiques.
- [ ] Vérifier les états de survol, focus, sélection et désactivation.

## Validation Windows

- [ ] Vérifier le rendu avec l’image PaperNest par défaut.
- [ ] Vérifier le rendu avec une image personnelle claire et sombre.
- [ ] Vérifier le rendu avec un fond couleur.
- [ ] Vérifier les pages Accueil, Détail, Recherche, Corbeille, Paramètres et Administration.
- [ ] Ajuster l’opacité et le flou à partir des captures réelles.
