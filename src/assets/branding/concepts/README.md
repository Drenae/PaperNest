# Concepts d’identité visuelle PaperNest

Ce dossier contient les premières pistes vectorielles du symbole compact PaperNest.

Ces fichiers ne sont pas encore utilisés par l’application. Ils servent uniquement à comparer les directions graphiques avant de créer les assets finaux.

## Palette commune

- Jaune PaperNest : `#F9A825`
- Anthracite de la rail : `#17191F`
- Fond clair de comparaison : `#F5F6F8`

## Concepts

### 01 — Fold

Fichier : `papernest_symbol_fold.svg`

Une feuille pliée simple et immédiatement compréhensible. C’est la piste la plus directe et la plus lisible aux petites tailles, mais aussi la moins distinctive.

### 02 — Stack

Fichier : `papernest_symbol_stack.svg`

Plusieurs documents superposés pour représenter le classement. Cette piste exprime mieux l’idée d’organisation et possède une silhouette plus propre à PaperNest.

### 03 — Box

Fichier : `papernest_symbol_box.svg`

Une boîte de rangement ou d’archives avec un document central. Cette piste est structurée et claire, mais son rendu est plus institutionnel.

## Planche de comparaison

`papernest_concepts_board.svg` présente les trois pistes sur fonds clair et sombre.

## Étape suivante

Après sélection d’une piste :

1. affiner les proportions et les courbes ;
2. vérifier le rendu à 16, 24, 32, 48 et 256 px ;
3. créer `papernest_symbol.svg` ;
4. dériver `papernest_logo.svg` ;
5. produire les PNG nécessaires ;
6. intégrer le symbole dans `PaperNestGlideRail`.
